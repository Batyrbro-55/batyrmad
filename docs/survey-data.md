# Нақты сауалнама нәтижелерін жариялау

Қазір сауалнама жинау қызметі қосылмаған. Сайттағы анкета — алдын ала қарау нұсқасы. Жауаптар жіберілмейді және сақталмайды. Қатысушылар мен нақты деректер болмайынша `public/survey-results.json` файлының `pending` күйін өзгертпеңіз.

1. Зерттеу жетекшісімен іріктеу, ерікті келісім және кәмелетке толмағандардың қатысу тәртібін бекітіңіз. Жинау басталарда деректерді кім, не үшін, қанша уақыт сақтайтынын түсіндіріңіз.
2. Анкетаны қағазда немесе келісілген бөлек қызметте өткізіңіз. Аты-жөнді, телефонды, нақты мектепті және аккаунт идентификаторын сұрамаңыз. Сервис қолданылса, электрондық пошта мен техникалық идентификаторлар жинау параметрлерін тексеріңіз.
3. Жеке жауаптарды ашық GitHub репозиторийіне салмаңыз. Тек тексерілген жиынтықтарды жариялаңыз. Қатысушысы 1–4 болатын санаттарды мағыналық тұрғыда біріктіріңіз немесе сұрақты жарияламаңыз; оларды нөлге ауыстырмаңыз.
4. JSON күйін `published` етіп, `sampleSize` өрісіне нақты қатысушылар санын, `period` өрісіне жинау күндерін, `sampling` өрісіне іріктеу тәсілін жазыңыз.
5. `questions` массивіндегі әр сұрақта `title` және `options` массиві болсын. Әр нұсқада `label` мен нақты бүтін `count` саны болуы тиіс. Нұсқалар қосындысы жалпы қатысушылар санынан аспауы керек. Бір сұраққа бір жауап: бірнеше жауапты сұрақтар бұл схемаға сәйкес емес.
6. Сайт әр сұрақтың пайызын сол сұраққа жауап бергендердің санынан есептейді. Өткізілген жауаптарды бөлек көрсетеді. Қате немесе тым ұсақ санаттары бар деректер жарияланбайды.

Нәтижелерді барлық Қазақстан жастарына жалпыламаңыз. Кездейсоқ емес іріктеу, өзіндік есеп және жауап бермеу шектеулерін қорытындыда сақтаңыз.

Ағылшын нұсқасы үшін `sampling_en`, әр сұраққа `title_en`, әр жауап нұсқасына `label_en` аудармаларын қосыңыз. `period` үшін екі тілге ортақ ISO күндерін қолданыңыз. Екі нұсқада да бірдей тексерілген сандар қолданылады; бөлек ағылшын статистикасын жасамаңыз.
